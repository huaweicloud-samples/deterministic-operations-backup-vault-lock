# 基于标签的不可变备份实践（华为云 CBR + KMS）

> 本实践介绍如何在华为云上构建一套「按标签纳管资源 + 定时自动备份 + 存储库不可变锁定（WORM）」的备份体系，适用于需要对关键负载做防篡改、防误删保护的场景。

## 1. 方案概述

通过华为云 **云备份（CBR）** 与 **密钥管理（KMS）** 组合实现：

- **备份存储库（CBR Vault）**：存放恢复点的容器，可开启「资源锁定」实现 WORM（一次写入、不可篡改、不可删除）。
- **备份策略（CBR Policy）**：定义备份执行频率与保留时长，并关联到存储库。
- **加密密钥（KMS）**：为备份数据提供客户管理的加密密钥与自动轮转。
- **资源纳管**：通过标签或直接指定资源 ID，将待备份资源关联到存储库。

## 3. 核心组件说明

| 组件 | 说明 | 关键参数 |
|---|---|---|
| CBR 备份存储库 | 恢复点容器；开启资源锁定后，锁定期间恢复点不可删除、不可修改 | `type`（server/disk）、`size`（GB）、`locked`、`policy_id` |
| CBR 备份策略 | 调度与保留规则 | `backup_cycle`（days/execution_times）、`long_term_retention.daily` |
| KMS 密钥 | 备份数据加密与密钥轮转 | `key_algorithm=AES_256`、`rotation_enabled=true` |

## 4. 不可变锁定（WORM）

CBR 存储库的「资源锁定」承担了一次写入可读、不可篡改的合规保护语义：

- 开启后，锁定期间存储库内的恢复点**无法被删除或修改**，有效防御勒索软件与误操作。
- 锁定动作具有不可逆性，请在确认备份范围与保留策略后再开启。
- 锁定冷却期与最短保留天数建议在控制台核对与设置。

## 5. 资源纳管方式

- **按 ID 绑定**：在存储库 `resources` 块中填入资源 ID 列表，适合已知固定资源。
- **按标签关联**：在控制台/API 以标签（如 `Backup=True`）批量筛选并关联到存储库，适合动态、规模化的资源纳管。

## 6. 适用场景

- 等保/合规要求不可篡改备份的数据库与关键业务系统。
- 需要统一调度、统一保留策略的多资源集中备份。
- 对备份数据有防勒索、防内部误删诉求的团队。
